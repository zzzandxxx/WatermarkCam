## 2. 水印绘制引擎（WatermarkPainter）

核心设计：**预览层与成片共用同一 `draw()` 方法**，保证所见即所得。

### 2.1 等比缩放体系

```java
final float k = (Math.min(W, H) / 1080f) * clamp(st.scale, 0.5f, 2.0f);
```

- 所有字号/边距/圆角都乘系数 `k`
- 基准取**画面短边**而非宽度：横拍（如 3000×4000 与 4000×3000）时水印视觉大小一致
- 用户缩放系数 0.5–2.0 叠加在 `k` 上

### 2.2 版面计算流程

1. 收集非空字段 → 生成「标签+内容」行（备注/地点过长自动折行，最多 3 行）
2. 测量各文本宽度 → 求内容块宽高（`contentW/contentH`）
3. 按模板决定 `fullWidth`（通栏）或自适应卡片宽度
4. 按位置（左下/右下/左上/右上）计算 `x0/y0`
5. 画背景（渐变/卡片/描边等 14 种）→ 画标题行（含 Logo）→ 时间 → 日期 → 分隔线 → 信息行

### 2.3 14 种模板

每个模板 = 背景 `drawBackdrop()` 分支 + 一组配色（标题/时间/日期/标签/内容/分隔线 6 色）。新增模板只需两处 switch 各加一个 case。

### 2.4 行级命中矩形

`draw()` 的重载接受 `Map<String, RectF> outRows`，绘制每行时回填「字段 → 矩形」（折行自动 `union` 合并）。字段常量：`F_TITLE/F_TIME/F_LOCATION/F_COORD/F_WEATHER/F_REMARK/F_PERSON/F_PROJECT`。预览层据此实现**点哪行改哪行**。

## 3. 今日水印式旋转

交互目标：**界面竖屏锁定，仅取景画面与成片跟随手机握持方向**。

### 3.1 三个同步量

`OrientationEventListener`（SENSOR_DELAY_NORMAL）感知物理角度，取整到 0/90/180/270 四档（55° 防抖）。方向变化时同步：

| 对象 | 竖握（ROTATION_0） | 横握（90/270） |
|---|---|---|
| 取景框比例 `photoBox.setRatio()` | 3:4 | 4:3 |
| 画面旋转 `photoBox.setContentRotation()` | 0 | 270/90（反向补偿） |
| 成片方向 `imageCapture.setTargetRotation()` | 0 | 90/270 |

### 3.2 AspectRatioLayout 的旋转实现

自定义容器只旋转 id 为 `cameraWrap` 的相机子容器：

- `onMeasure`：旋转 90/270 时对相机子容器按交换后的宽高测量（覆盖层不交换）
- `onLayout`：相机子容器居中放置后 `setRotation(θ)`；覆盖层始终铺满取景框

**关键点**：水印/网格覆盖层不参与旋转，其坐标系恒等于成片坐标系，因此水印位置、行级点击命中在旋转前后都精确对应成片。

### 3.3 成片方向

拍照时 CameraX 按 `targetRotation` 写入 EXIF；`ImageUtils.decodeOriented()` 解码时按 EXIF 旋转还原 → 再画水印 → 横拍得横版成片。

## 4. 拼图与汇报（CollageMaker）

纯 Canvas 合成，无第三方图片库：

| 模式 | 布局 | 输出 |
|---|---|---|
| 拼图 | 长图竖排 / 宫格（列数=⌈√n⌉，居中裁切） | 宽 1080 深底 |
| 汇报 | 标题+元信息+说明+逐张照片（带时间说明）+页脚 | 宽 1080 白底，上限 12000px |

- 源图统一解码到长边 1600，防 OOM
- 汇报长图先「测量总高→创建位图→逐段绘制」两遍式布局；照片超出 4:3 比例时上下居中裁切
- 生成后 `ImageUtils.saveToGallery()` 存入 MediaStore（Android 10+ 无需存储权限），分享走 FileProvider

## 5. 数据层

| 类 | 存储 | 内容 |
|---|---|---|
| Prefs | SharedPreferences | 水印字段/样式/拍照偏好/自定义地点/时间模式等 40+ 键 |
| RecordStore | SQLite | 拍摄记录（uri/time/title/location/remark），按时间倒序索引 |
| LogoStore | 私有目录 PNG | 企业 Logo（导入时自动去底/裁边/方形归一化，带版本迁移） |

照片保存：Android 10+ 走 MediaStore `RELATIVE_PATH=Pictures/水印打卡`；Android 9 及以下直接写公共目录（Manifest 已按 `maxSdkVersion=28` 声明旧存储权限）。

## 6. 稳定性设计

- **CrashGuard**：全局异常处理器，闪退堆栈连同机型信息写入 `Android/data/<包>/files/crash_*.txt`（保留最近 5 份），供无法连 adb 时定位
- 旋转链路全部 try/catch 防御（相机重配竞态）
- 大图解码统一走 `inSampleSize` 两段式 + 长边限制，拍照后台线程处理防卡帧
- 拍照 700ms 防抖；定位 12s 超时；传感器档位 55° 防抖
